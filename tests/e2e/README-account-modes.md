# Account-mode E2E contract

Full account profiles expose five mutually exclusive operating modes: Summary, Sales, Field, Evidence, and History. Hosted tests must select the mode that owns the evidence they assert instead of expecting every report section to remain visible simultaneously.

The responsive release gate additionally requires the Workflow command grid to stack to one column below 980px, keep map/inspector/table widths within the viewport, and preserve row selection on iPhone/WebKit.
